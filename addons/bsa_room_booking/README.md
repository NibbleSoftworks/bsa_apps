# BSA Room Booking

Status: planning dan foundation setup.

Addon ini akan menangani room catalog, booking request, approval, controlled override, calendar staff, notification, dan requester self-service untuk BSA.

Belum ada `__manifest__.py` atau production model. Manifest baru dibuat setelah architecture decision mengonfirmasi exact Odoo Community dependencies untuk milestone M0.
