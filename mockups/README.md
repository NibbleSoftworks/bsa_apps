# Mockups

Folder ini untuk prototype dan mockup non-production.

Mockup bukan source of truth untuk architecture, security, access control, atau business rules. Setiap mockup harus memiliki README yang menjelaskan tujuan, cara menjalankan, status, limitation, dan demo credentials jika ada.

Mockup room booking yang dibuat mahasiswa akan ditempatkan di `mockups/room_booking/` setelah file diperiksa dan path asset dirapikan.
