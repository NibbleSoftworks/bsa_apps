# Security policy

## Melaporkan vulnerability

Jangan membuat public issue jika laporan berisi cara bypass permission, akses ke private booking data, credential, atau vulnerability yang dapat langsung dieksploitasi.

Gunakan GitHub private vulnerability reporting jika sudah diaktifkan untuk repository ini. Jika belum tersedia, hubungi maintainer organisasi NibbleSoftworks melalui jalur private yang tercantum pada profil organisasi.

Sertakan:

- versi atau commit yang terdampak;
- langkah reproduce minimum;
- impact yang terlihat;
- apakah real personal data atau credential mungkin sudah terekspos;
- saran perbaikan jika ada.

Jangan menyertakan real booking document, contact pribadi, password, token, atau database dump di laporan.

## Scope awal

Project masih berada pada tahap planning dan foundation setup. Security policy akan diperbarui sebelum pilot production, termasuk supported versions dan response expectations.
